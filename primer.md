# История прогресса: Вайбкодер — Лендинг-калькулятор

## Цели проекта
- Привлекать клиентов на услуги автоматизации
- Давать быстрый ориентир по стоимости через калькулятор
- Конвертировать в заявки через Telegram и Max

## Прогресс

### 2026-05-06
- Проект инициализирован через /init
- Реализован лендинг по wireframe-дизайну из claude.ai/design (DOSS-стиль)
- Калькулятор рабочий: 6 типов задач, слайдер сложности, 4 доп. опции
- 4 карточки «Для кого», выровненные по нижней метке «боль:»
- Модальное окно «Получить точный расчёт» → выбор Telegram / Max с заготовкой сообщения
- Кнопки в финальном CTA: Telegram + Max

## Архитектурные решения
- Весь лендинг — один файл `index.html` (стили + разметка + JS встроены)
- Калькулятор считает цену на клиенте через JS, без бэкенда
- Базовые цены: bot 15k, reports 8k, parser 12k, crm 20k, dashboard 25k, custom 10k
- Доп. опции: срочно ×1.3, обучение +5k, поддержка +5k, интеграция +10k
- Ссылки на мессенджеры — в константах TG_USERNAME и MAX_USERNAME в JS
