# Вайбкодер — Лендинг-калькулятор

Лендинг с интерактивным калькулятором стоимости автоматизации. Аудитория — предприниматели, бизнесмены и самозанятые с ручными процессами.

## Стек
Чистый HTML/CSS/JS — без фреймворков. Google Fonts: Inter + JetBrains Mono.

## Запуск
Открыть `index.html` в браузере — никакой сборки не нужно.

## Структура
```
калькулятор/
├── index.html    — весь лендинг (5 секций, калькулятор, CTA)
├── CLAUDE.md     — контекст и правила для Claude Code
├── primer.md     — история прогресса и архитектурные решения
└── памятки/      — технические заметки по ходу работы
```
